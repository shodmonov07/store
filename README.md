# Django E-Commerce App

This is a simple e-commerce site built with Django.  
Includes product listing, cart system, user authentication, and admin panel.

## Features:
- Add to cart / remove from cart
- Login / Signup system
- Product filtering
- Admin dashboard (Django admin)
- PostgreSQL integration

## Technologies:
- Python 3
- Django 4.x
- HTML / CSS / Bootstrap
- PostgreSQL (default)
